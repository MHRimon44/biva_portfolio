# Design reference

The full VoltAgent awesome-design-md collection is downloaded locally at
`awesome-design-md/` (ignored by Git). The selected Claude design guide is installed
at the project root as `DESIGN.md`. The accompanying MIT license is retained here.

Source: https://github.com/VoltAgent/awesome-design-md

The portfolio adapts the guide's cream canvas, serif typography, warm terracotta,
restrained borders, and editorial spacing. Illustrations are CSS/SVG compositions,
not photographs or screenshots of completed software.
